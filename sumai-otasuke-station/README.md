# 住まいのお助け便利屋ステーション WordPressテーマ

便利屋サービスとレンタル・コミュニティスペースを同格で訴求する、独自LP型テーマです。外部テーマ、ページビルダー、有料プラグイン、ACFには依存しません。

## 動作要件

- WordPress 6.4以上
- PHP 7.4以上
- HTTPS環境を推奨

## インストール

1. 管理画面の「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」を開きます。
2. `sumai-otasuke-station.zip` を選択してインストール・有効化します。
3. 「設定 → 表示設定」でホームページ表示を確認します。`front-page.php` がトップページとして表示されます。
4. 「外観 → カスタマイズ → 店舗・LP設定」で各情報を設定します。
5. 「設定 → パーマリンク」で「変更を保存」を1回押します。

## 編集できる内容

- サイトロゴ（WordPress標準カスタムロゴ）
- メイン／サブコピー、2つのCTA、ヒーロー画像
- 電話、LINE、メール、住所、営業時間、定休日、GoogleマップURL
- スペース面積、定員、レンタル料金、スペース画像
- 便利屋サービス4枠のタイトル、項目、画像
- OGP画像、meta description
- フォームプラグインのショートコード
- お知らせ、便利屋施工事例、スペース利用事例、FAQ（カスタム投稿）

## フォーム

テーマは独自のメール送信処理を持ちません。Contact Form 7等でフォームを作成し、ショートコードを「お問い合わせフォーム」に設定してください。未設定時は電話・LINEへの案内を表示します。

## SEO

WordPress標準のタイトル・XMLサイトマップを利用します。テーマはdescription、canonical、OGP、LocalBusiness、FAQPage、パンくずを出力します。未設定の電話・住所詳細・営業時間は構造化データへ追加しません。SEOプラグインを導入する場合は、重複出力を避けるためテーマ側SEOの停止対応を検討してください。

## 画像

初期ヒーローには、本サイト用に制作した横長の街並みイラストを使用しています。そのほかの同梱SVGは差し替え用の仮画像です。管理画面ではWebP/JPEG/PNGを利用できます。推奨比率はヒーロー約2:1、スペース5:4、事例3:2、OGP 1200:630です。アップロード時は内容を説明する代替テキストを入力してください。
